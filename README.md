# Not maintained
It was quite a fun project, which I built over a few years, and I am thankful for the large community. For alternatives [see below](#alternatives).  
There are a few reasons for EOL.  
## Project's state
It needed a rewrite from scrath. I think it was my first big project, so the code quality is poor.
## Approach to game data
There is a bit better one but it is different from the code here. I implemented it in CRDE.
## Money
I never intended this project to earn money. In FOSS, the currency to make software is enthusiasm.  
A bit of story. I was excited for this project, I am glad people use it even today (though there are complications). I did not really know much back then about reverse-engineering, but I had a goal of decrypting this game data. I spent enormous amount of time learning and trying all possible solutions until I succeeded. At first this app worked only on Google accounts (I wonder how much people remember original SKDE, probably just me, Star, and dsf). This app was made initially for about three and a half people, now we have a few thouthands users that joined [Discord server](https://discord.gg/mwHgFXp), and even more that chose to edit on their own (I don't blame them). I was satisfied with what I've done.  
Over the years, I noticed that some people were selling saves, I didn't mind it at first but now those people are hard to ignore.
I am displeased with amount of people that profit off this without giving anything back. Therefore, I am not motivated to continue developing it and adapting it to new encryption.
Anyone can fork it ofc, the encryption keys are trivial to get, just be ready that they might be not universal.

# Alternatives
I rebuilt this project from scrath and even made support for Otherworld Legends - [CRDE](https://crde.pages.dev/). It does not require root and can edit save on any platform (meaning iOS save editing is supported).

# Soul Knight Data Editor (discontinued)
## Features
### File manager
Edit game files without encryption.
### Backup manager
Backup your game progress. Account ID removed automatically.
You can pick backup file from storage in app or open file with SKDEditor.
### Spoofer
Spoof device and account information.
